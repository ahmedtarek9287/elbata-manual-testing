# elbata-manual-testing
Manual test cases for the Elbata e-commerce demo.
This repository contains manual test cases for the Elbata
e-commerce training website.

## Application Under Test

[Elbata website](https://ehabmekky.github.io/Elbata/index.html)

## Testing Scope

The test cases cover:

- Registration and login
- Product catalog and product details
- Shopping cart and checkout
- Order confirmation
- Navigation and user session
- Business rules and non-functional requirements

## Test Documentation

The test cases were prepared using the Elbata SRS.

[Open the test cases file](Batta_Test_Cases_SRS_Reviewed.xlsx)

The Excel file includes test steps, test data, expected results,
priority, and requirement IDs.

## Execution Status

The test cases are documented but have not yet been executed.
Actual results and execution status should be updated after testing.
